# Mascot Intro V9 — Canvas pipeline + boot-delay placeholder

Branch: `experiment/mascot-canvas-v9`

## Trilemma da chiudere

1. **Smooth** (no scatti) mobile + desktop
2. **Luccichio bracciale + collana** visibile
3. **Niente boot delay** — mascotte visibile dal primo paint

## Diagnosi corretta del luccichio

Il "luccichio" sui bordi metallici (bracciale + collana BS) **NON è
presente nei webp frame originali**. È un artefatto visivo della
pipeline canvas, prodotto dalla combinazione di 3 parametri:

| Parametro                          | Effetto sul luccichio                                                                                               |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `createImageBitmap(blob)` defaults | `premultiplyAlpha:"default"` moltiplica RGB×alpha sui pixel semi-trasparenti dei border highlights → bianchi spinti |
| Canvas backing DPR-scaled (cap 2)  | `canvas.width = intrinsicW * dpr` + `ctx.scale(dpr,dpr)` → upsample bilineare amplifica i pixel chiari              |
| `imageSmoothingQuality: "high"`    | smussa il glow risultante in un alone diffuso                                                                       |

V8 (`premultiplyAlpha:"none"` + backing 1:1) li aveva rimossi tutti
e tre cercando di "preservare fidelity": ha ucciso il luccichio +
ha gonfiato la RAM (101 bitmap × 1920×1080×4byte ≈ 800MB) ⇒
eviction su mobile/desktop ⇒ scatti pure su PC.

## V9 — la ricetta

```ts
// Pre-decode all 101 frames in parallel:
const bm = await createImageBitmap(blob); // defaults preservano il luccichio

// Canvas setup at playFrom():
const dpr = Math.min(window.devicePixelRatio || 1, 2); // CAP 2
canvas.width = Math.round(intrinsicW * dpr);
canvas.height = Math.round(intrinsicH * dpr);
ctx.scale(dpr, dpr);
ctx.imageSmoothingEnabled = true;
ctx.imageSmoothingQuality = "high";

// Per-frame:
ctx.clearRect(0, 0, intrinsicW, intrinsicH);
ctx.drawImage(bitmaps[frame], 0, 0, intrinsicW, intrinsicH);
```

## Boot-delay fix

Stack `<img frame0> + <canvas>` nello stesso wrapper. Entrambi con
`object-cover object-[36%_bottom]` → visivamente identici.

- `bitmapsReady=false`: `img opacity:1, canvas opacity:0`
- `bitmapsReady=true`: opacity swap 200ms cross-fade

L'utente vede il frame 0 dal primo paint mentre i bitmap pre-decode
in background. Quando ready, swap impercettibile e parte la
rAF loop sul canvas.

## Lifecycle events (invariati da V0)

```
bs-mascotte-start   → playFrom() entry
bs-mascotte-reveal  → frame ≥ 50
bs-mascotte-end     → fade-out completed
bs-mascotte-bypass  → external abort
```

## Fallback

Se `bitmaps[0]` decode fail dopo `Promise.all`, dispatch automatico
di `bs-mascotte-bypass` → la gate non resta in attesa di eventi che
non arrivano.
